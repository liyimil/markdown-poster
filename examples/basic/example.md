# markdown-poster：一键生成小红书图文

## 这是什么

**markdown-poster** 是一个极简命令行工具，把你写的 Markdown 文章自动排版成精美图片卡片。你只管写内容，排版的事交给它。

> 一行命令，10 秒出 18 张图，每张都是 3:4 比例，社交平台最优尺寸。

## 能做什么

- **自动分页**：优先在 H2 标题处断页，大章节继续拆分，短页自动合并
- **双主题**：米白 `light` 和暗黑 `dark`，一键切换
- **代码高亮**：程序员友好，技术文章最佳伴侣
- **表格渲染**：Markdown 表格自动转为美观的数据卡片
- **头像 + 作者区**：首页自带作者信息和圆形头像
- **页码和页脚**：每页底部自动标注，读者不会迷路

## 快速上手

```bash
# 安装
pip install -e .
playwright install chromium

# 一行出图
markdown-poster article.md --auto-paginate -t "文章标题" -a "作者名"
```

输出默认在 `output/` 目录，文件名 `01.png` 到 `N.png`，直接拖进小红书即可发布。

## 参数一览

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--auto-paginate` | 开启自动分页 | 关闭 |
| `--chars-per-page` | 每页目标字数 | 500 |
| `--max-pages` | 最大页数限制 | 25 |
| `--theme` | light 或 dark | light |
| `--format` | png / webp / jpeg | png |
| `--fixed-height` | 固定 1080×1440 | 自适应 |

## 适用场景

无论你是 **小红书博主**、技术写作者、还是想做知识分享的创作者，只要你有 Markdown 稿件，markdown-poster 就能帮你 **省掉手动排版的时间**：

1. **技术博客**：代码块 + 表格 + 流程图，一张图讲清一个概念
2. **读书笔记**：摘录 + 批注，翻页式呈现
3. **教程系列**：分章节截图，一套图就是一堂微型课
4. **产品文档**：功能介绍 + 参数表，清爽耐看
